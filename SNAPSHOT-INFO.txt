本地录音 · 源码快照说明
========================

版本：Android 2.3.8（对应 git 标签 android-v2.3.8）
用途：**自包含源码快照**，解压后即可编译出 dist-android 里的那个 APK。

与 git 仓库的区别
------------------
git 仓库（本目录下的 .git）只跟踪**源码**（约 120 个文件 / 2 MB），把体积大但可重新获取的
东西排除在外（见 .gitignore）：
  * 模型（storage/，约 2.6GB）
  * 预编译依赖（android/app/libs/sherpa-onnx.aar，54MB）
  * 第三方源码（android/third_party/llama.cpp，203MB）
  * 构建产物（android/app/.cxx、app/build、.gradle）
  * APK（dist-android/*.apk）

本 zip 快照**额外包含**了上面这些（除模型和构建产物），所以解压即可编译。

里面有什么
----------
  app/                    电脑版（Windows）Python 源码 + 全部自检脚本
  android/                Android 版源码
    app/src/main/java/      录音/ASR/标点/OCR/大模型/VAD/音频导入解码/下载/前台服务
    app/src/main/cpp/       JNI：llm_jni.cpp（llama.cpp）、ocr_jni.cpp（ORT C API）
    app/src/main/assets/    OCR 识别字典（18708 字符）
    app/src/main/res/       应用图标（全密度）
    app/src/test/           JVM 单元测试（VAD 断句、音频质量判据，共 9 个用例）
    app/libs/               sherpa-onnx.aar（预编译依赖）
    third_party/llama.cpp/  交叉编译用的 llama.cpp 源码（来自 llama-cpp-python 0.3.36 源码包）
  scripts/                验证脚本（ASR 对比、VAD 对比、Silero 测试、图标生成、OCR 参数提取…）
  dist-android/           已构建好的 APK + 图标/界面预览图
  installer/              Windows 安装包脚本（Inno Setup）
  config.yaml / docs/     电脑版配置与设计文档
  README-windows.md       电脑版说明
  android/README-android.md  Android 版说明（含完整版本记录 1.2.0 → 2.2.0）

怎么重新编译 Android 版
------------------------
工具链（都在 E 盘）：
  E:\android-dev\jdk           JDK 17
  E:\android-dev\sdk           Android SDK + NDK r27 + cmake 3.22.1
  E:\android-dev\gradle        Gradle 8.9
  E:\android-dev\gradle-home   Gradle 缓存

  $env:JAVA_HOME        = "E:\android-dev\jdk"
  $env:ANDROID_HOME     = "E:\android-dev\sdk"
  $env:GRADLE_USER_HOME = "E:\android-dev\gradle-home"
  & "E:\android-dev\gradle\bin\gradle.bat" --no-daemon -p android assembleRelease

  单元测试（不需要模拟器）：
  & "...\gradle.bat" --no-daemon -p android :app:testDebugUnitTest

如果 android/third_party/llama.cpp 缺失（例如只从 git 检出源码），用这个命令补回来：
  pip download llama-cpp-python==0.3.36 --no-binary :all:
  然后解压 tar.gz，把 vendor/llama.cpp 的内容放到 android/third_party/llama.cpp/

模型（不在此快照中，可重新下载）
--------------------------------
App 首次运行会自己从 ModelScope 下载（转写 227MB / 标点 285MB / OCR 132MB /
神经网络断句 2.3MB / 大模型 1.49GB）。电脑版模型在 storage/ 下（已排除），来源见 README-windows.md。

自检入口（不需要 UI，可自动化验证）
----------------------------------
  adb shell am start -n com.localrecord.app/.MainActivity --ez livetest true --ez nodownload true
      → 实时转写：3 遍语音 + 第二个会话 + 12 秒纯噪声（期望噪声 0 段）
  adb shell am start -n com.localrecord.app/.MainActivity --ez audiotest true --ez nodownload true
      → 导入解码：files/audiotest.{ogg,flac,mp3}
  adb shell am start -n com.localrecord.app/.MainActivity --ez ocrtest true --ez nodownload true
  adb shell am start -n com.localrecord.app/.MainActivity --ez downloadtest true
  结果写到 /sdcard/Android/data/com.localrecord.app/files/*-result.txt
