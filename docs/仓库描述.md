## 二、项目详细描述（可贴到 Release 说明、论坛、分享文案）

```
【本地录音】完全离线的安卓录音转写 + 图片文字识别

一句话：录音、转文字、加标点、识别图片里的字，全部在手机本地完成，不联网、不上传任何数据。

■ 功能
· 语音：录音（切后台继续录）、实时转写（中英混说）、神经网络 VAD 自动断句、自动标点
        文字自动滚到最新、右侧拖动条翻长文、一键复制
· 录音库：导入 mp3/wav/m4a/aac/ogg/flac/amr 并自动转写；播放可拖进度；删除；显示文件路径
· 文档问答：选图 → 离线 OCR 识别（中英数字）→ 一键复制

■ 为什么小
· 安装包约 36MB（只含 arm64），模型不打包进 APK，首次运行自动下载（约 634MB）
· 从 ModelScope 下载（失败自动回退 hf-mirror），支持断点续传、后台下载

■ 技术上
· Kotlin + Jetpack Compose
· 语音识别/标点/VAD：sherpa-onnx（Paraformer 中英混说 + CT-Transformer 标点 + Silero VAD）
· OCR：PP-OCRv6（ONNX Runtime）
· 音频解码：Android 原生 MediaExtractor + MediaCodec
· 自研音频判据（信噪比 / 谐波性 / 过零率）均带 JVM 单元测试

■ 权限与隐私
· 只申请录音、通知、网络（仅用于下载模型）、前台服务、唤醒锁
· 识别过程完全不联网；录音文件存在应用私有目录，卸载即删除

■ 系统要求
· Android 8.0（API 26）及以上，arm64 手机
· 开源协议：MIT
```

## 四、v3.0.1 发行版说明（Releases 页面用）

```markdown
## 本地录音 Android 3.0.1

完全离线的安卓录音转写 + 图片文字识别。

### 本版内容
- 移除本地大模型（会议纪要/问答），只做语音识别与 OCR
- 安装包从 96MB 压到 **36MB**（只出 arm64；不再编译 llama.cpp；开启 R8 瘦身）
- 需要下载的模型合计约 634MB（首次运行自动下载，有进度通知、断点续传）
- 修复 OCR 英文单词粘连（字典缺了空格字符，导致 "Risk 2026" 被识别成 "Risk2026"）
- 底部加入项目介绍；新录音 / 新转写都会先清空上一次内容
- 实时转写：自动滚到最新、右侧可拖动、一键复制

### 安装
1. 下载下方 `LocalRecord-android-3.0.1.apk`（35.9MB）
2. 手机点击安装（首次可能提示"未知来源"，允许即可）
3. 首次打开会自动下载识别模型，下完即可用（建议 WiFi）

### 环境
Android 8.0+ / arm64-v8a。识别全程在手机本地完成，不联网、不上传任何数据。
```
