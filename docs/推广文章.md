# 本地录音 · 产品介绍

## 这是什么

一个安卓 App：**录音 → 本地转成文字 → 自动加标点 → 逐句翻译（中英互译）**。

所有计算都在手机本地完成，**不联网、不上传任何内容**。

---

## 有什么功能

| 功能 | 说明 |
|---|---|
| **实时转写** | 边说边出字，中文、英文、中英混说都能认 |
| **自动断句** | 说话停顿约 1 秒自动切一句，不用手动分段 |
| **自动标点** | 出来的文字自带标点，不是一串没有停顿的字 |
| **逐句翻译** | 每识别出一句立刻翻译：中文→英文、英文→中文自动判断方向；原文下面直接显示译文；底部有开关，想关就关 |
| **录音库** | 导入手机里的音频（mp3 / wav / m4a / aac / ogg / flac / amr）并自动转写；播放可拖进度；**分享、另存为、重命名、删除**都有 |
| **一键复制** | 顶部「复制」＝带时间戳；底部「去时间戳复制」＝纯文字，直接粘进会议纪要 |
| **后台继续录** | 切到别的 App、甚至锁屏，录音和转写都不会断 |
| **离线可用** | 模型下完之后，飞行模式也能正常转写和翻译 |

---

## 能帮你解决什么

| 你遇到的麻烦 | 这个 App 怎么帮 |
|---|---|
| 开会/上课/采访录了音，回去要一句句听、一句句敲 | 边说边出字，录完文字已经在手机里了，直接复制走 |
| 要写会议纪要，但录音里一堆"嗯、那个、然后" | 自动断句 + 自动标点，出来的就是能读的文字 |
| 英文会议、外文资料听不懂 / 中文内容要发给外国同事 | 逐句翻译，中英互译自动判断方向，原文译文对照看 |
| 担心会议内容（人名、金额、客户信息）被上传到别人服务器 | **全程不联网、不上传**，录音只存在手机私有目录，卸载即删 |
| 在地铁、飞机、信号差的地方也要记录 | 不依赖网络，下完模型就能一直用 |
| 微信/邮件要发录音，或者要存到别的文件夹 | 录音库里直接「分享」或「另存为」 |
| 录音文件太多、名字看不出是啥 | 可以「重命名」，也能直接看到文件路径 |
| 只想要纯文字稿，不要「[0] [12]」这种时间戳 | 底部「去时间戳复制」，一键拿到干净文本 |

## 需要什么系统

| 项目 | 要求 |
|---|---|
| 系统版本 | **Android 8.0 及以上** |
| CPU 架构 | **64 位（arm64）** —— 近几年的手机基本都是 |
| 安装包大小 | **约 41MB**（模型不打包在里面，所以很小） |
| 首次使用 | 需要联网**下载模型（约 911MB）**，之后可完全离线使用 |
| 权限 | 只需要：麦克风、通知（下载/录音进度）—— 联网仅用于下载模型 |

> 说明：转写相关的模型（约 514MB）先下完，**就能开始转写了**；翻译模型（397MB）排在后面，下完翻译自动生效。

---

## 下载模型需要多久

模型合计约 **911MB**，时间取决于你的网速：

| 你的网速 | 大约需要 |
|---|---|
| 20 MB/s（家里千兆 WiFi） | **约 1 分钟** |
| 10 MB/s（普通 WiFi） | **约 2 分钟** |
| 5 MB/s（较好 WiFi / 5G） | **约 3 分钟** |
| 2 MB/s（4G / 一般宽带） | **约 8 分钟** |
| 1 MB/s | **约 15 分钟** |

* 支持**断点续传**：中途断了、退出 App、关机都行，下次打开接着下；
* 支持**后台下载**：切到别的 App 或锁屏也能继续下，通知栏有进度；
* 建议用 **WiFi**（第一次下完就再也不用下了）。
