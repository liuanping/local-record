## 正文

### 一、先说痛点

开会、采访、上课，录了音回去还是要一句句听、一句句敲。市面上的录音转写要么**要联网**（录音先上传到别人服务器），要么**要付费**，要么装完发现是个「壳」——真正的识别在云端跑。

我自己最别扭的是两点：

* **隐私**：会议里有人名、金额、客户信息，凭什么先传到别人服务器上？
* **可用性**：地铁里、飞机上、信号差的地方，联网方案直接趴窝。

所以我做了个**完全离线**的安卓 App：**本地录音**。

### 二、它是什么

一个把「录音 → 转文字 → 自动标点 → 逐句翻译」整套流程都放在**手机本地**跑的安卓 App。

说人话就是：**你对着手机说，屏幕上就出字；每出一句，下面立刻跟一行英文（或中文）译文。全程不联网、不上传任何内容。**

### 三、核心功能

| 功能 | 说明 |
|---|---|
| **实时转写** | 边说边出字，中英混说都认；说错不用管，整段录音也完整存下来 |
| **自动断句** | 用神经网络 VAD（Silero）判断"你是不是说完了"，停顿约 1 秒自动收一段 |
| **自动标点** | 出来的文字自带标点，不是一串没有停顿的字 |
| **逐句翻译** | 每识别出一句立刻翻译：中文→英文、英文→中文自动判断方向，原文下面直接显示译文，可一键开关 |
| **录音库** | 导入 mp3 / wav / m4a / aac / ogg / flac / amr 并自动转写；播放可拖进度；分享、另存为、重命名、删除都有 |
| **一键复制** | 列表顶部复制（带时间戳）/ 底部「去时间戳复制」（纯文本，直接粘进纪要）|
| **后台继续录** | 切到别的 App 甚至锁屏，录音和转写都不中断 |

### 四、为什么"离线"值得单独说

* **录音、转写、翻译全部在手机上算完**，一个字节都不上传；
* App 里唯一的网络请求是**首次启动时从魔搭（ModelScope）下载模型文件**，下完之后你甚至可以开飞行模式用；
* 录音存在应用私有目录，卸载即删除，不会莫名其妙出现在某个云盘里。

对需要处理**合同、病历、客户名单、内部会议**的人来说，这一条比什么功能都重要。

### 五、技术上怎么做到的（给同行的部分）

* **语音识别**：sherpa-onnx + Paraformer 中文模型（int8 量化，227MB），中英混说识别；
* **标点**：CT-Transformer（285MB）；
* **断句**：Silero VAD（2.3MB 的神经网络模型），比能量法准得多，也不会把空调声当人声；
* **翻译**：llama.cpp + **Qwen3-0.6B**（Q4_K_M，397MB），跑在手机 CPU 上；
* **音频解码**：直接用 Android 原生 `MediaExtractor` + `MediaCodec`，所以手机上能播的格式都能转写；
* **界面**：Kotlin + Jetpack Compose。

工程上比较有意思的几个点，也顺手记一下：

1. **段前回退 1.6 秒**：神经网络 VAD 要确认 0.2~0.25 秒才判定"有人说话"，所以真正检测到时，开头那半个字已经被切掉了。做法是往回多取 1.6 秒音频（真实音频优先，不够用静音补），但**严格不超过上一段的结束位置**，这样既不丢字也不重复。
2. **KV 缓存要清、前缀要留**：多句连续翻译时，如果不清理上下文，第二句会接在"上一句的问题+答案"后面继续编，表现就是**每句都翻成同一个词**；但每次都全清又会浪费——系统提示词是固定的，于是改成**只丢弃不同的尾巴，保留公共前缀**。实测同方向连续翻译，预填充从 78 token / 5.1 秒降到 18 token / 1.3 秒，**快约 3 倍**。
3. **思维链默认关闭**：Qwen3 的对话模板是默认"先想再答"的，对逐句翻译这种短任务纯属浪费时间。做法是在推理层把模板里没闭合的 `<think>` 补成空块，强制它直接输出译文——实测输出只有 8~19 个 token，没有多余的"内心戏"。
4. **音量归一化**：手机麦克风电平差异极大，太轻的输入会让识别丢字，所以每段都归一到目标峰值（最多放大 10 倍，带限幅）。

### 六、体积为什么这么小

**APK 只有约 41MB**（只含 arm64），因为**模型不打包进安装包**：

| 模型 | 大小 |
|---|---|
| 语音识别（Paraformer） | 227MB |
| 标点（CT-Transformer） | 285MB |
| 断句（Silero VAD） | 2.3MB |
| 翻译（Qwen3-0.6B） | 397MB |
| **合计** | **约 911MB** |

首次打开自动下载（默认从魔搭拉，失败自动回退 hf-mirror），**支持断点续传、后台下载**，建议用 WiFi。

### 七、怎么装

1. 手机点开下载链接，下载 APK（约 41MB）；
2. 点击安装（首次可能提示"未知来源"，允许即可）；
3. 打开 App，等它把模型下完（约 911MB，有进度和通知），下完即可离线使用。

### 九、已知局限（说清楚更省事）

* 翻译用的是 **0.6B** 的小模型，**日常口语、短句、术语基本够用，长难句和文学性表达会力不从心**（后续计划加 1.7B 档位可选）；
* 识别效果和**手机麦克风**关系很大：安静环境下不错，嘈杂环境会掉字；
* 目前只出 arm64，老设备（32 位）装不了。
